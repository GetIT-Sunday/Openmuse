# OpenMuse 偏好记忆

Stage 6 增加可确认、可编辑、可忘记的跨会话**写作偏好**。
它不自动收藏所有对话，不是论文知识库，也不能代替发布审批。

## 怎么用

1. 在对话里说：“记住：我的文章主要面向工程师，表达克制，不要标题党。”
2. 模型可以提出偏好。点击输入框上方的“偏好待确认”，或输入 `/memory`。
3. 选择一条提议，检查内容、来源和范围，按“确认保存”。不合适就“不保存”。
4. 新建会话并提出相关写作请求，控制器会读取符合条件的已确认偏好。

也可以直接在 `/memory` 面板点“新增”，无需模型理解意图或联网。
每个范围、类别保留一个当前值；修改已保存的条目并再次确认，会替换该值。
旧提议不能覆盖已经更新的值，冲突时需要刷新、重新编辑。

```text
/memory         查看、确认、编辑和忘记偏好
/memory off     暂停检索和模型提议；已有记录保留
/memory on      重新启用
/forget ID      忘记指定偏好，ID 可在面板详情里查看
/forget         仅清空当前会话上下文，不删除长期偏好或文章
```

面板支持 Tab 导航、列表方向键、Enter 选择/确认、Esc 关闭。
“忘记”会清除该范围、类别的记录内容及待确认替换提议，避免旧提议复活。
已有聊天、模型请求快照和文章不会因此删除；如果当前对话原话仍包含旧要求，
模型仍可能读到它。开始新会话或清空本会话上下文，可分开处理这两类信息。
有待恢复的对话时，不允许清空上下文后又通过旧快照恢复回来。

## 保存什么

支持目标读者、表达风格、解读深度、避免事项和关注主题五类偏好。
每条记录包含来源会话/轮次、适用范围、版本、更新时间和有效期。

- **此项目**：当前项目的会话共享。
- **论文 Pack**：只在 `autowechat/research-to-wechat` 语境中检索。
- 有效期默认一年；手动编辑可选 90 天、一年或长期。过期记录不检索，仍可查看/删除。
- 模型只能提出提议，无法调用确认、忘记、开启记忆或发布审批的接口。
- 待确认提议会在本地暂存以支持退出恢复，但不作为已确认偏好检索。

TUI 数据存储在项目的 `data/preferences.sqlite3`，该目录已被 Git 忽略。
新数据库权限为 `0600`，内容没有加密；不要把它当作密码保险箱。
常见 API Key、Bearer 和密码赋值形式会被拒绝保存为偏好，但这不是完整的敏感信息检测器。
删除时清除数据库中的文本并保留空的幂等凭据；不承诺擦除系统备份或以前的聊天日志。

## 如何使用，哪里有边界

检索只读取未过期、已确认、范围匹配的记录，采用中文双字词/英文词的本地匹配，
以及当前写作任务语境。关注主题必须有文本重合；通用写作偏好仅在相关语境中加入。
默认最多使用约 1800 个保守预算单位，并按本轮剩余上下文空间缩小。
该算法可解释但不理解所有同义表达，**不是向量语义检索**。
它只选择背景资料，不决定聊天/工作流分流，也不会因为命中词语启动任务。

优先级为：**当前用户要求 > 当前任务约束 > 当前 Pack 偏好 > 项目通用偏好**。
这项语义理解依赖模型；Runtime 的审批、安全边界不依赖偏好文字。
控制器将偏好标为背景数据，提示模型把适用的要求传入写作工具参数，不强行覆盖本次参数。
尚未接入跨项目全局档案、自动历史导入、情节记忆、论文全文召回或向量数据库。
旧 `MemoryManager` 仍是编辑模板默认值，不会自动变成用户已确认的偏好。

本轮接入 TUI 的 `ConversationController`。其他客户端可注入独立的
`PreferenceMemory(path, profile=...)` 实例复用服务；CLI/MCP 并未自动改用此存储。
服务不额外调用嵌入或摘要模型；自然语言提议仍使用正常对话模型及其工具回合。
`memory.proposed/retrieved/confirmed/rejected/forgotten/settings_changed` 进入同一会话事件流，
事件只记录 ID、类别、范围和数量等元信息，不再复制偏好正文。

## 验证

`tests/test_stage6_memory.py` 覆盖确认门禁、跨会话读取、隔离、预算、相关性、过期、
修改冲突、忘记后的恢复、暂停使用、损坏记录，以及三种尺寸的 Textual 键盘操作。
全部使用离线模型脚本，不创建真实微信草稿。

可用 `.venv/bin/python docs/audits/capture_memory_visuals.py` 重新生成三个尺寸的终端截图。
