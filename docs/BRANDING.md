# OpenMuse 品牌边界

OpenMuse 是整个 AIGC Harness 的产品名称，不绑定某个模型、平台或内容渠道。

AutoWechat 是 OpenMuse 的第一个官方 Pack，负责这一条核心工作流：

```text
研究论文或主题 → 选择材料 → 生成中文文章 → 对话修改 → 手机预览 → 可选创建微信草稿
```

| 名称 | 身份 | 使用位置 |
| --- | --- | --- |
| OpenMuse | Harness 主品牌 | TUI、会话、模型、记忆、Runtime、Pack 管理 |
| AutoWechat | 官方 Pack | 论文转公众号文章工作流 |
| SmearglePaper | 兼容名称 | Python 模块、旧 CLI、历史数据目录 |

兼容入口暂时保留：

```bash
smearglepaper tui
openmuse tui
```

新能力、文档和用户界面统一使用 OpenMuse；不要再把 Harness 本身称为 AutoWechat 或 SmearglePaper。
