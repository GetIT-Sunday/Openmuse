🎨 SmearglePaper

AI 论文自动化写作与发布助手

功能 安装 快速开始 CLI 命令 MCP 服务

✨ 功能特性

📄 论文收集

  • 从 arXiv 收集最新论文
  • 从 AI 工程 RSS/Atom 订阅源收集博客
  • 从 GitHub Trending 收集热门项目
  • 按主题相关性、新鲜度排序

📝 文章生成

  • 使用 PyMuPDF 下载解析 PDF
  • 提取图表候选
  • 用 LLM 生成中文深度解读文章
  • 支持 DeepSeek/OpenAI 兼容 API

🔍 质量审查

  • 文章质量评分
  • LLM 编辑优化
  • 本地模板兜底
  • Evidence-first 写作流程

📱 微信发布

  • 生成微信公众号兼容 HTML
  • 创建封面图
  • 创建/更新微信草稿
  • MCP 工具支持

🚀 快速开始

一键运行完整流水线

smearglepaper agent-run --topic agents --days 30 --top-k 5

🛠️ CLI 命令

命令说明
smearglepaper topics列出可用主题预设
smearglepaper collect收集 arXiv 论文
smearglepaper collect-blogs收集 AI 博客
smearglepaper collect-github收集 GitHub Trending
smearglepaper rank排序论文
smearglepaper write生成文章
smearglepaper agent-run运行完整流水线
smearglepaper daily-digest每日摘要
